Gauge is an edge-oriented industrial machine-health intelligence system designed to detect unusual machine sounds and identify early signs of equipment degradation.

The project explores how intelligent machine monitoring can operate locally while minimizing the need to upload raw audio to cloud services.

**Key engineering capabilities**

- Privacy-preserving local audio anomaly detection
- Machine-specific degradation trend analysis
